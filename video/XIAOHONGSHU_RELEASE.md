## 推荐正文（可直接复制）

同时用 Codex、Claude Code、opencode 写代码，用起来很顺，但每天到底用了多少 Token，总得分别翻记录。

于是我做了 Token Meter，一个放在 Windows 系统托盘里的用量小窗。

点一下展开，看完再收起，不需要一直开着一个大窗口。

它可以：
📊 查看今日、7天、30天和全部用量，按 Agent 或模型分组。
🔎 展开 Codex 的输入、缓存、输出和推理明细。
🪟 分别调节玻璃不透明度和模糊度，让小窗融入桌面。

不需要填写 API Key，从支持来源的本地日志读取用量；也支持当前用户登录自启。

这段视频展示了小窗的开合和玻璃效果，数字都是演示数据。

目前只统计本机支持来源，不统计 ChatGPT 网页/手机用量，也不是会员剩余额度。Cursor 是估算，费用是用量折算，不是正式账单；按设备分类还在待开发。

源码和安装说明：
https://github.com/Disc13/token-meter
