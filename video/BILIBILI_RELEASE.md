## 标题

多个 AI Agent，一个用量小窗｜Token Meter

## 简介

我做了一个 Windows 本机 Agent token 用量统计工具：Token Meter。

一个托盘小窗，查看今日、7 天、30 天及全部用量，按 Agent / 模型分组，并查看趋势与 Codex 输入、缓存、输出、推理明细。玻璃背景的不透明度和模糊度可独立调节。

支持来源：Codex CLI / Desktop、Claude Code、Command Code / cmdc、opencode、Devin CLI、Cursor。其中 Cursor 为估算；具体日志格式与接入范围以仓库 README 为准。

视频中的数字均为演示数据；费用为用量估价，不代表订阅实际扣款。当前仅统计本机支持来源的日志，不支持 ChatGPT 网页 / 手机用量或账户剩余额度；按设备分类仍待开发。

源码与安装说明：https://github.com/Disc13/token-meter

动画使用 React / Remotion 制作，中文宋体、英文 Times New Roman；配乐由程序原创合成，没有使用第三方音乐采样。
